### UX-01 · Главная как новый пользователь
- **Было:** до вопроса — выбор «Короткий / Полный / Режим исследования»; на 390 он выше быстрых задач (`screens/before/home-390-fold.jpg`).
- **Ожидалось:** вопрос или задача без выбора глубины.
- **Причина:** `showModes` на главной и на странице задачи; сам режим для большинства задач менял только плотность вёрстки.
- **Компоненты:** `app/[specialty]/(workspace)/page.tsx`, `ask/page.tsx`, `profile-settings.tsx`, `answer-mode.ts`.
- **Исправление:** переключатель убран; в профиле — честная настройка «Разбор исследований по умолчанию».
- **Автотест:** unit `UX-01`, e2e `UX-01`, `product-shell.spec.ts`.
- **Браузер:** на 390 в первом экране поле, примеры, первая задача и «Все задачи»; главная 7614 → 5256–5720 px (зависит от ленты).
- **Артефакт:** `screens/after/home-390-fold.jpg`.

### UX-02 · «Что нового» и «Что нового для меня»
- **Было:** одна проверка (`updates_monitor → whats_new`) под двумя именами, на двух страницах; «Консилиум» — тот же ответ под третьим именем.
- **Причина:** каталог строился по агентам, а не по функциям.
- **Исправление:** одно имя «Что нового», одна страница; «Консилиум» убран; в каталоге одно имя — один адрес («Мероприятия в ленте», «Обучение в ленте» для фоновых проверок); вопрос «Что нового по …» не подменяет фоновую проверку и её расписание.
- **Компоненты:** `lib/agents/definitions.ts`, `lib/portal/agents-gallery.ts`, `agents/page.tsx`, `server/agents/workspace.ts`, `server/agents/supervisor.ts`.
- **Автотест:** unit `UX-02`, e2e `UX-02`, `agent-workspace.spec.ts`.
- **Браузер:** подтверждено субагентом B, раунды 2–4.

### UX-03 · Длительность антибиотикотерапии при ВП у взрослых
- **Было:** обзоры у детей; при малом числе совпадений поиск сужался до `(pneumonia[tiab])` — опухоли, лимфомы; «Коротко» не о длительности.
- **Причина:** «у взрослых» не распознавалось; уточнение «внебольничная» терялось; расширенный поиск не помечался; «Коротко» сортировал по дате.
- **Исправление:** популяция «взрослые» исключает педиатрию по заголовку; уточнения и модификаторы тяжести; пометка `questionMatch`; «Коротко» — только выводы по теме и о спрошенном; «Искали по: …» и «Не учтено в поиске: …».
- **Компоненты:** `lib/portal/lexicon.ts`, `server/mesh/sources/pubmed.ts`, `lib/mesh/evidence-graph.ts`, `lib/mesh/compiler.ts`, `components/experience/experience-view.tsx`, `lib/portal/unmatched.ts`.
- **Автотест:** unit `UX-03` (5 тестов, в том числе фикстура «длительность раньше антибиотиков» и «фраза о панели — не ответ»), e2e `UX-03 + UX-04`.
- **Браузер:** первым в «Коротко» — BMJ Open 2023 «3–5 дней» (`screens/after/ux03-therapy-1440-fold.jpg`); выдача PubMed без ключа меняется между запусками, поэтому порядок проверен также на фикстуре.
- **Разбор по исследованиям (D-7):** метки, тип, текст о выводах авторов и порядок по популяции исправлены в `f9caa98`; своя страница сценария с параметрами сохранена по `docs/agent-mvp/DECISION.md` (UXR-17).

### UX-04 · «А если течение нетяжёлое?»
- **Было:** новый вопрос с просьбой назвать заболевание (`screens/before-matrix/ux04-followup-1440.jpg`).
- **Причина:** уточнение без своей темы не связывалось с вопросом; после первой правки ответ брался из кэша чужого вопроса — ключ кэша не включал модификаторы (найдено субагентом A в раунде 2).
- **Исправление:** зависимое уточнение, в том числе «а при беременности?», «а при ХБП?», продолжает вопрос. Шапка называет исходный вопрос, шаги и заменённую популяцию. Ключ кэша включает все распознанные условия.
- **Компоненты:** `lib/portal/continuation.ts`, `server/portal/manager.ts`, `lib/mesh/intent.ts`, `ask/page.tsx`, `portal-input.tsx`.
- **Автотест:** unit `UX-04` (3 теста, в том числе цепочка из двух уточнений), `R-A-01`; e2e `UX-03 + UX-04`.
- **Браузер:** подтверждено A в раунде 3: новый поиск с `non-severe`, без «из недавно проверенных».

### UX-05 · «Аторвастатин: противопоказания»
- **Было:** «Коротко» с показаниями, затем все разделы и исследования (8230 px на 390).
- **Исправление:** спрошенные разделы инструкции первыми — в любой задаче, если назван препарат; остальное свёрнуто; у пункта есть подпись раздела и отметка сокращения; повторы между модулями убраны.
- **Компоненты:** `lib/mesh/refine.ts` (`askedSections`), `server/mesh/executor.ts`, `lib/mesh/compiler.ts`, `experience-view.tsx`.
- **Автотест:** unit `UX-05`, `R-A-03`; e2e `UX-05`.
- **Браузер:** 8230 → 2911 px на 390, противопоказания первыми.

### UX-06 · Источник есть, но не отвечает
- **Было:** «Подтверждено источником» у работ не по вопросу; «Проверяемость: высокая».
- **Исправление:** метка сверки — «Совпадает с текстом источника» или «Требует сверки · причина»; отдельная метка соответствия — «По условиям поиска», «Шире вопроса», «Тема вопроса в выводе не названа»; строка «Искали по / Не учтено».
- **Автотест:** unit `UX-06` (2 теста, рендер), e2e `UX-03 + UX-04`.

### UX-07 · «Изменений нет» и «Нет тем для поиска»
- **Было:** нули по категориям при «Нет тем для поиска»; «Готово» при 0 находок.
- **Исправление:** единый словарь `runOutcome`; категория без поиска — «не проверялось»; первая проверка считает найденное; выключенная проверка не наполняет ленту.
- **Автотест:** unit `UX-07 / UX-10` (7 состояний), e2e `agent-workspace.spec.ts`.

### UX-08 · «Что изменилось в рекомендациях?»
- **Было:** список публикаций под заголовком «Что изменилось».
- **Исправление:** вопрос об изменениях открывается сравнением с предыдущей версией; без указанной предыдущей версии — честная фраза; без вопроса — «Версии рекомендаций»; расширенные публикации не выдаются за версии.
- **Автотест:** unit `UX-08`, e2e `UX-08`, `skills-flows.spec.ts`.

### UX-09 · «Кратко» в материале
- **Было:** новый поиск по теме и «Полный ответ».
- **Исправление:** «Кратко» убран; материал — краткая форма, без заглушек; поиски по теме подписаны как новые и ведут обратно к материалу.
- **Автотест:** unit `UX-09`, e2e `UX-09`.

### UX-10 · Источник недоступен или нет ответа
- **Было:** «Готово · 0.0 с · 0 находок» на «???»; примеры не из кардиологии.
- **Исправление:** «Проверка не выполнялась»; «Готово частично» называет источник; при изменившейся странице повтор не предлагается; примеры своей специальности; подсказка до отправки предупреждает.
- **Автотест:** unit `UX-07 / UX-10`, e2e `UX-10`.
