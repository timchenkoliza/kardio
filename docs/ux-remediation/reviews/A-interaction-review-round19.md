- **Где:** `lib/portal/router.ts`, правило `events`. Отрицательный просмотр назад перечисляет только «сосудист-, неблагоприятн-, коронарн-, тромботическ-, кардиоваскулярн-, ишемическ-, клиническ-, больш-, жизнеугрожающ-, геморрагическ-, тромбоэмболическ-».
- **Вживую:**
  - кардиология, «Нежелательные события при приёме апиксабана» (`hx-5`, `hx-5-390-fold.png`): форма пишет «Покажем профессиональные события · апиксабан», дальше AHA Scientific Sessions 2026 и «Перейти к регистрации»;
  - «Цереброваскулярные события при ФП» (`hx-14`) → афиша;
  - эндокринология, «Сердечно-сосудистые и почечные события при СД 2 типа» (`ev-3`) → афиша.
- **Офлайн, все специальности** (`events-jobs.txt`): «Серьёзные нежелательные события при терапии статинами», «Почечные события при иНГЛТ-2», «Кардиальные события после внесердечных операций», «Повторные события после инфаркта миокарда», «Аритмические события при ХСН», «Частота событий при ХСН».
- **Почему P1:**
  - нежелательные явления препарата — вопрос безопасности;
  - врач получает список конференций, а другого пути нет — надо догадаться переформулировать.
- **Минимальное исправление:** перевернуть правило.
  - Голое «событи» ведёт в афишу только при её признаке: «конференц-/конгресс-/вебинар-/мероприят-/школ-/форум/съезд/афиш-/календар-/регистрац-», «ближайшие/предстоящие/профессиональные события», «события по <специальности>/в <месяце>».
  - Иначе вопрос клинический.
- **Критерий:**
  - девять вопросов выше → «Ответ по источникам», форма пишет «Покажем ответ по источникам»;
  - «Конференции по ХСН», «Мероприятия по ХСН», «События по кардиологии в ноябре», «Ближайшие события по кардиологии», «Какие события в кардиологии в этом месяце» → афиша.

**N19-2. Не регрессия, найден сейчас. В справке по нескольким препаратам открывается только инструкция первого — молча**

- **Где:**
  - `server/mesh/sources/medi.ts:596` и `openfda.ts:72` берут только `intent.entities.drugs[0]`. В f85d764 то же (`medi.ts:552`);
  - план «Я проверю» (`lib/mesh/strategy.ts:96`) обещает «Открою российские инструкции: <все>»;
  - «Искали по» перечисляет все препараты.
- **Шаги и что видно:** кардиология, PubMed исключён.
  - «Апиксабан или варфарин при ФП» (`dx-0`):
    - «Искали по: фибрилляция предсердий · антикоагулянты · апиксабан · варфарин.»;
    - показания, противопоказания, безопасность и дозирование — все из «Эликвис 2.5 мг»;
    - о варфарине ни слова: ни в «Не учтено», ни в «Чего не хватает».
  - «Апиксабан, ривароксабан, дабигатран или эдоксабан у пожилых с ФП»:
    - план (`hx-7-390-fold.png`, `doac4-plan-390.png`) обещает три инструкции;
    - после «Продолжить» (`doac4`, `doac4-390-fold.png`) в «Коротко»: «Дозирование · МЕДИ РУ: …дозу препарата снижают до 2,5 мг два раза в сутки…» — без названия препарата;
    - инструкция одна — Эликвис.
- **Почему P1:**
  - подпись и план обещают то, чего действие не делает;
  - врач сравнивает препараты, а получает данные по одному и не знает об этом;
  - правило снижения дозы апиксабана в «Коротко» без названия препарата легко отнести к другому ПОАК.
- **Минимальное исправление:**
  - в «Искали по» оставить только препараты, чья инструкция открыта;
  - остальные назвать: «Инструкции: варфарин — не открывалась, смотрите ГРЛС»;
  - в строке источника в «Коротко» называть препарат («Дозирование · Эликвис (апиксабан) · МЕДИ РУ»);
  - лучше — запрашивать инструкцию по каждому препарату, не больше трёх.
- **Критерий:**
  - «Апиксабан или варфарин при ФП» без PubMed: либо обе инструкции, либо явная строка про варфарин;
  - каждое утверждение «Коротко» называет свой препарат;
  - план перечисляет только то, что действительно откроет.
