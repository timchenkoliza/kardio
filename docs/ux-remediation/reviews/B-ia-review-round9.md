### N9-01 · P2 · давний (был в маршруте раунда 8), остаток критерия N8-01 · шаг маршрута АГ — «что нового» в рекомендациях по СН
1. **Место.**

   - `server/agents/services/learning.ts:79–87`: шаг «<тема>: что нового в <titleRu>», причина «Свежие международные рекомендации по вашей теме».
   - Фильтр по названию из b3368b3 действует только на PubMed-обзоры.
   - В «Для вас» тот же снимок — карточка рекомендаций «ESC 2026: сердечная недостаточность» с причиной «Тема: Артериальная гипертензия».
2. **Путь.** Кардиология → тема АГ → `/agents/learning`. Шаг 2 из 5: «Артериальная гипертензия: что нового в ESC 2026: сердечная недостаточность · 5 ключевых изменений…». К АГ относится одно из пяти: «Целевое САД ниже 130 мм рт. ст. при АГ…».
3. **Структура.** Шаг «что нового» входит в маршрут темы под её именем, только если тема — предмет документа. Если тема затронута одним утверждением, шаг называется по документу, а причина — по утверждению: «Касается вашей темы: целевое САД < 130 мм рт. ст. при АГ (1 из 5 изменений)». То же для причины карточки в «Для вас».
4. **Названия.** «Что нового в ESC 2026: сердечная недостаточность»; метка «Касается темы «АГ»: 1 изменение».
5. **Переходы** без изменений. Шаг открывает снимок с цитатами, начиная с относящегося к теме утверждения.
6. **Что переиспользовать.** `assertions[]` снимка, `titleNamesTopic` (по `title` снимка), `reasonShown`.
7. **Критерий.** В маршруте АГ нет шага с префиксом «Артериальная гипертензия:», если исходное название документа не называет гипертензию. Причина такого шага цитирует совпавшее утверждение.

- **Вернувшийся врач.** «История» / «Последние вопросы» → тот же разбор в том же режиме. «Для вас» → учебный шаг → «Отметить пройденным» → следующий шаг по теме. Состояние выключенной проверки по-прежнему не видно в профиле и на «Все задачи» (N-05r).
