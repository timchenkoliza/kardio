### N13-02 · P1 · остаток N12-1 (ревью A) · «ХСНсФВ» и «ХСНунФВ» не сужаются, а заголовок пишет «по вопросу»; «СНнФВ» не находит ХСН
1. **Место.**
   - `known()` (`research-answer.ts:197`) считает «ХСНсФВ» учтённым: ключ «снсфв» входит в слово.
   - `PHENOTYPE` (`lib/portal/unmatched.ts:47`) сравнивает слово целиком и без «х».
   - Ключа и фенотипа «сннфв» нет. Комментарий в `unmatched.ts` при этом называет «СНнФВ».
2. **Путь (по коду, `hf-headline-4a50241.json`).**
   - «иНГЛТ-2 при ХСНсФВ» → «Нашли N публикаций PubMed по вопросу. Искали по: хсн · инглт-2». Термин без фенотипа.
   - «Финеренон при ХСНсФВ у пожилых» → тоже «по вопросу».
   - Для сравнения «…при СНсФВ» → «не по всему вопросу. Не учтено: «СНсФВ»».
   - «иНГЛТ-2 при СНнФВ» → тема ХСН не найдена, «Не учтено: «сннфв»» — строчными, не так, как написал врач.
3. **Структура.** Фенотип в любом написании находит ХСН и всегда назван в «Не учтено» так, как его написал врач. Варианты: (Х)СН + с/н/п/ун/сн + ФВ.
4. **Названия.** «Не учтено в поиске: «ХСНсФВ»».
5. **Переходы.** Без изменений.
6. **Что переиспользовать.** `PHENOTYPE` → `^х?сн(?:с|н|п|ун|сн|р)?фв$`, такие же ключи ХСН, матрица тестов.
7. **Критерий.** Для СНсФВ, ХСНсФВ, СНнФВ, ХСНнФВ, СНунФВ, ХСНунФВ, СНпФВ:
   - «Искали по: хсн …»;
   - фенотип назван как написан;
   - заголовок «не по всему вопросу».
