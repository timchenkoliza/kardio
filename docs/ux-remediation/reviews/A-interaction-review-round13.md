## Новые дефекты

### P1

**N13-1. Другие формы записи фенотипа ХСН. Остаток класса N12-1**

- **Где:**
  - `lib/agents/vocabulary.ts:26` — в ключах темы «ХСН» нет «сннфв»;
  - `lib/portal/unmatched.ts:47` — `PHENOTYPE = /^(?:снсфв|снунфв|снпфв|снснфв|снфв|снрфв)$/u`: нет «сннфв», а якорь `^` не пропускает форму с приставкой «Х».
- **Шаги:** «Разбор по исследованиям» → «РФ + международные» → «ХСНсФВ у пожилых», «ХСНунФВ у пожилых», «СНнФВ у пожилых», «ХСНнФВ у пожилых».
- **Что будет, офлайн:** тот же путь вживую дал результат для «СНсФВ» (`hf-variants.txt`, `n12-1-offline.txt`, `exec-terms.txt`):
  - «ХСНсФВ / ХСНунФВ / ХСНпФВ у пожилых» → «Искали по: хсн · пожилые пациенты», **«по вопросу»**, «Не учтено» пусто. Запрос — общий `"heart failure" AND elderly`. Сохранённая фракция выброса при этом молча потеряна, хотя для «СНсФВ» коммит её честно называет;
  - «СНнФВ у пожилых» и «ХСНнФВ у пожилых» → темы нет, запрос в PubMed только `elderly`, «Искали по: пожилые пациенты. Не учтено: «сннфв»» (в нижнем регистре). Вживую «Только РФ» по «СНнФВ» → «Темы не выбраны — смотрим всю специальность» (`ru-snnfv.txt`).
- **Почему P1:**
  - для ХСНсФВ экран говорит «по вопросу», а показывает работы о сердечной недостаточности вообще. Данные по СНнФВ на СНсФВ не переносятся — это вводит в заблуждение;
  - СНнФВ — основное сокращение в российских рекомендациях по ХСН, но по нему ищется «пожилые вообще», и врач не может получить ответ.
- **Минимальное исправление:**
  - добавить «сннфв» в ключи «ХСН»;
  - `PHENOTYPE = /^х?сн(?:н|с|ун|п|сн|р)?фв$/u`;
  - в «Не учтено» показывать токен в исходном регистре.
- **Критерий:**
  - «СНнФВ у пожилых», «ХСНнФВ у пожилых» → «Искали по: хсн · пожилые пациенты. Не учтено: «СНнФВ»» (или «ХСНнФВ»), в запросе есть `"heart failure"`;
  - «ХСНсФВ у пожилых» → «Не учтено: «ХСНсФВ»», «не по всему вопросу»;
  - «СНсФВ у пожилых», «Хроническая СН у пожилых», «Катетерная аблация при ФП у пожилых» и «ПОАК у пожилых с ФП» — как сейчас.

**N13-2. Регрессия 4a50241. Ожил ключ «лёгочн»: любое слово «лёгочн…» даёт тему «Лёгочная гипертензия»**

- **Где:** `lib/agents/vocabulary.ts:33`, ключи `["легочн гипертенз", "лёгочн", "лаг", "хтэлг"]`. На c3786f5 ключ «лёгочн» никогда не срабатывал из-за «ё». Теперь ключи приводятся к общему виду (`:276`), и он совпадает с любым «лёгочн…».
- Те же `topicsMentioned` используют разбор (каталог и PubMed), `compileIntent` главной и маршрутизатор.
- **Шаги, вживую без PubMed:** «Только РФ» → «Изоляция лёгочных вен при ФП у пожилых» (`ru-pvi.txt`, `ru-pvi-390-fold.png`, `ru-pvi-768-fold.png`).
- **Что видно:**
  - «Нашли 5 материалов каталога…», «Искали по: фибрилляция предсердий · лёгочная гипертензия»;
  - **первая карточка — «Легочная гипертензия, включая хроническую тромбоэмболическую легочную гипертензию» (2024), третья — она же в версии 2020** с меткой «есть более новая версия»;
  - на c3786f5 тот же вопрос давал только три карточки по ФП (`exec-terms.txt`).
- **С PubMed, офлайн:** запрос `("atrial fibrillation" OR "pulmonary hypertension") AND ablation AND elderly`.
- **Другие вопросы:**
  - «Тромбоэмболия лёгочной артерии у пожилых» → «Искали по: лёгочная гипертензия», запрос `"pulmonary hypertension" AND elderly`, «Не учтено: «тромбоэмболия», «артерии»» (`ru-tela.txt`);
  - «Сердечно-лёгочная реанимация у пожилых» на главной → `cardiology:ph` (`intent-offline.txt`).
- **Почему P1:**
  - на вопрос об изоляции лёгочных вен — то есть об абляции при ФП — первой показана клиническая рекомендация по другой болезни;
  - в «Искали по» вписано условие, которого в вопросе нет.
- **Минимальное исправление:**
  - удалить одиночный ключ «лёгочн». Лёгочную гипертензию покрывают «легочн гипертенз», «лаг» и «хтэлг», а тест «нет мёртвых ключей» пройдёт, потому что ключа больше нет;
  - добавить отрицательные тесты.
- **Критерий:**
  - «Изоляция лёгочных вен при ФП у пожилых» → без «лёгочная гипертензия» в «Искали по», в запросе PubMed и в `compileIntent`; в «Только РФ» нет карточек «Легочная гипертензия…»;
  - «Тромбоэмболия лёгочной артерии…» и «Сердечно-лёгочная реанимация…» → нет темы «Лёгочная гипертензия»;
  - «Лёгочная гипертензия у пожилых» → тема «Лёгочная гипертензия» остаётся.
