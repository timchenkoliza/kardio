- **Честность при сбоях** (`lib/portal/run-outcome.ts`): «Готово частично · Сейчас не читается: МЕДИ РУ — показано то, что дали остальные источники»; «Это не значит, что изменений или публикаций нет». При layout_changed результат не подставляется.
- **Разбор по PMID:** HR 0.79; 95% ДИ 0.69–0.90; N=5988 и конечная точка совпадают с аннотацией EMPEROR-Preserved, рядом дословная цитата. Есть фраза «Продукт не превращает их в рекомендацию». readEffect не придумывает чисел: для ARR возвращает null, пустое поле остаётся пустым.
- **Метки проверки МЕДИ РУ:** «Требует сверки · Вторичный источник; сверьте в ГРЛС».
- **Проверка отсутствия упоминания:** «упоминание группы препаратов под другим названием не исключено».
- **Актуальность:** вычисленный срок пересмотра КР 2016 и метка «пересмотр документа просрочен».
- **Блок «Расхождения»** («Продукт не решает, какой источник прав»).
- **Границы применимости:**
  - граница для инструкции США в карточке FDA;
  - каждая выдержка из инструкции называет препарат, дату и отмечает сокращение;
  - для второго препарата прямо сказано «инструкция открыта только для…».
- **Маскирование:** СНИЛС, телефон, «д.р.», ФИО с ролью и ФИО с отчеством маскируются, исходник в БД не попадает.

- **Маршрутизация «событий»:** 14 формулировок — клинические «события» уходят в вопрос, а афиша только при явном слове-сигнале.
- **«Не учтено в поиске»** называет условия, которые поиск не использовал.
