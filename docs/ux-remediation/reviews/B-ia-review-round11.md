## Новые дефекты

### N11-01 · P2 · проблема с ширины 768 видна на 1024–1100 · таблица разбора переносит слова посреди слова
1. **Место.**
   - `app/styles/research-consumer.css`: карточки включаются по ширине окна (`@media (max-width: 1023px)`), а не по ширине области контента.
   - Если окно шире, боковая панель оставляет таблице 660–736 px, на колонку — 114–128 px.
   - Перенос `overflow-wrap: break-word` теперь рвёт слова, а не выталкивает их за ячейку.
2. **Путь.** «Найти статьи» на окне 1024 px (iPad в горизонтальном положении, узкое окно ноутбука).
   - **1024 px:** «Рекоменда/ции РКО», «Клиническ/ие рекоменда/ции», «Публикаци/я», «многоцент/ровое».
   - **1100 px:** «Рекомендаци/и».
   - **1180 px:** переносов нет.
   - Метка «Совпадает с источником · версию сверьте · карточка…» на 1024 занимает 10 строк.
3. **Структура.** Вид таблицы зависит от ширины её контейнера (container query на `.ws-research-table-wrap`): меньше ~880 px — карточки, как на 768. Либо порог по окну с учётом боковой панели (~1180 px).
4. **Названия.** Без изменений.
5. **Переходы.** Без изменений.
6. **Что переиспользовать.** Уже существующая разметка карточек (`td[data-label]`).
7. **Критерий.** На 1024, 1100 и 1180 в колонках «Источник», «Тип» и «Проверка» 0 переносов посреди слова (перенос по дефису допустим). Горизонтального переполнения нет.
- Файлы: `s6-research.json → tableFit1024`, `s6c-russia-articles.json → tableFit{1024,1100,1180}`, `shots/s6-research-table-1024.png`, `shots/s6c-russia-articles-table-1024.png`.

Таблица, сравнение, «Что проверили», «Обзор», экспорт и `/ask` теперь одна система меток. Вне её остаются «Что нашли» в «Кратком обзоре» (N11-03) и список литературы (N11-02).
- **Новый врач.** Тема → лента с честными причинами. Три документа ESC одного снимка подписаны однородно, без ложного «частично».
- **Опытный врач.** «Найти статьи» → таблица → экспорт: метки и проверки РКО совпадают везде. На окне 1024 таблица рвёт слова (N11-01), список литературы указывает базу данных вместо журнала (N11-02).
- **Вернувшийся врач.** «История» → тот же разбор, режим и метки → «Повторить…» в том же режиме. Состояние выключенной проверки в профиле по-прежнему не видно (N-05r).

## Что не проверено
- **Окружение:** хранение с `DATABASE_URL`.
- **Только по коду или через эндпоинт:**
  - «Краткий обзор» и «Академическая основа» с записями PubMed — разрешён один разбор с PubMed. Экспорт этих режимов взят через эндпоинт с `mode=`; карточка `Study` для записей PubMed — по коду.
  - Режим «Найти статьи» со строкой без совпадения — `export-code.json`.
  - Сборку LaTeX не запускала: сравнивала только содержимое.
- **Вне моей области (область A):** реально ли поиск по каталогу в «Только РФ» учёл «антикоагулянты» и «пожилые пациенты», названные в «Искали по»; правка «Не учтено в поиске» (N10-1).
- **Специальности:** педиатрию, акушерство и эндокринологию не проверяла.
- **Выдача PubMed** меняется между запусками: сменились учебные карточки АГ и ХСН.
