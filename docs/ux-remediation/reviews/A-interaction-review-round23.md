### P2

- **N23-2. Регрессия: запрос афиши уходит в ответ.**
  - **Что видно:** «Ближайшие очные события по ХСН» → «Не учтено: «ближайшие очные события»», кнопка «Мероприятия по теме» на 1 455 px (`g11`).
  - **Масштаб — около 25 формулировок во всех специальностях:**
    - «Ближайшие очные/бесплатные/зарубежные/европейские/актуальные события по …»;
    - «Значимые/Ожидаемые/Лучшие/Яркие/Знаковые/Петербургские события…»;
    - «Расписание событий по ХСН», «Посещение событий по ХСН»;
    - «События ОССН/ЕОК/НМИЦ/ВНОА», «События аритмологии»;
    - «Самое ожидаемое событие года»;
    - «Аккредитованные события НМО» → обучение.
  - **Причина:**
    - `clinicalAdjective` по умолчанию считает клиническим любое прилагательное вне разрешённого списка и проверяется раньше «ближайшие»;
    - существительные на -ие («расписание», «посещение») принимаются за прилагательные;
    - любая кириллическая аббревиатура после «события» считается болезнью.
    - Обратная сторона, давняя: префиксы «ин»/«мо» в `LISTING_ADJECTIVE` делают «Инфекционные/Интраоперационные/Мозговые события» афишей. Теперь у них хотя бы есть блок наверху.
  - **Исправление:**
    - «ближайш/предстоящ» проверять раньше `clinicalAdjective`;
    - клиническими считать прилагательные из списка клинических основ;
    - аббревиатуру считать болезнью, только если её знают `conceptsIn` или `topicsMentioned`.
  - **Критерий:** эти формулировки → афиша, набор N22-1 остаётся ответом.
