## Структура и три пути
- **Верхний уровень** не менялся: Главное · История · Мои материалы · Обезличивание · Профиль.
  - «Все задачи» и страницы проверок — вторичные под «Главное».
  - Разбор — своя страница сценария с параметрами (DECISION.md). Его результат из любой двери показывается в режиме запуска.
  - Убрать: шаблонный заголовок «… по теме «…»» для непроверенной темы.
