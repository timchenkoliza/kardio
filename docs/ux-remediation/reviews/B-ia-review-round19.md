1. **Место.**
   - `lib/portal/router.ts:47`: «событи» не ведёт в афишу только сразу после прилагательного из списка (сосудист-, неблагоприятн-, коронарн-, тромботическ-, кардиоваскулярн-, ишемическ-, клиническ-, больш-, жизнеугрожающ-, геморрагическ-, тромбоэмболическ-).
   - У семьи `events` нет «Что дальше» (`lib/mesh/compiler.ts:221`, `FOLLOW_UPS`).
2. **Путь сейчас** (`r19-route-62b4d68.txt`, `route2-62b4d68.txt`). Эти вопросы получают `portal=events`, `mesh=event_search`:
   - «Нежелательные события при приёме апиксабана», «Нежелательные события на фоне апиксабана» — препарат назван, а побеждает афиша;
   - «Серьёзные нежелательные события при терапии статинами»;
   - «Кардиальные события у пожилых», «Частота кардиальных событий у пожилых», «Кардиальные события после некардиальных операций»;
   - «Цереброваскулярные события при ФП» — в кардиологии и неврологии;

5. **Переходы.** Если афиша всё же выбрана при клиническом контексте — «Что дальше: Ответ по источникам», один клик.
