   - **АГ:** подряд «Рекомендации 2026: артериальная гипертензия — ведение пациентов» (ISH, только для Африки), «Рекомендации 2026: артериальная гипертензия» (ACR, критерии визуализации при реноваскулярной АГ), «Рекомендации: артериальная гипертензия» (ренальная денервация, Япония).

   - `issuersOf` / `publicationFacts` (добавить ISH и «Африка»);
   - `.pt-original-title`;
   - `localizeItem` с `basis: "template"` для неполного распознавания.
7. **Критерий.**
   - В одной ленте нет двух карточек с одинаковым заголовком без учёта года и суффикса.

### R7-02 · P2 · остаток R6-02 · тема АГ засчитывает «pulmonary hypertension»
1. **Место.**
   - `lib/agents/vocabulary.ts:27`: `hypertension[tiab]` → `[ti]`.
   - `server/agents/executors.ts`: `titleNamesTopic` ищет подстроку «hypertension» и не учитывает, что «pulmonary hypertension» — отдельная тема `ph` того же словаря.
   - Запасной ход в `scopeReason`: если в названии нет ни одной темы, перечисляются все темы профиля, то есть прежнее поведение.
2. **Путь.** Тема АГ → «Для вас» → «Рекомендации: лёгочная гипертензия — медикаментозное лечение и диагностика» (Brazilian Thoracic Society) → «Почему вы это видите: Тема: Артериальная гипертензия». Сама карточка подписана честно («лёгочная гипертензия»), неверна только причина.
3. **Структура.** Если название называет другую тему словаря («pulmonary/portal/intracranial/ocular hypertension»), АГ не засчитывается. Документ уходит в «Шире темы» на странице проверки либо получает свою тему. Если совпадения нет: «Найдено в PubMed по запросу «…»», а не все темы профиля.
4. **Что переиспользовать.** `topicsMentioned` / `topicById` для проверки на чужие темы, `pt-widened`.
5. **Критерий.** С темой АГ ни у одного документа про лёгочную, портальную или внутричерепную гипертензию нет причины «Тема: Артериальная гипертензия».
