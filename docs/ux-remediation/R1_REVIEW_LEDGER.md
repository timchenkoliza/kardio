Релизный кандидат R1 — `release/r1` @ `8d2d1a9`: main, PR #28, #27, #26 и `fix/ux-recovery`. Его проверили три ревьюера по `docs/REVIEW_PROTOCOL.md`, независимо и на одном SHA. Отчёты лежат без изменений:
