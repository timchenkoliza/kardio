# Kardio × дизайн-система Yandex Med — правки для Claude Code

Аудит прода https://kardio-eta.vercel.app от 21 октября 2026 года.

**Что проверено**

- **Страницы:** `/cardiology`, `/cardiology/agents`, `/cardiology/materials`, `/cardiology/settings`, `/cardiology/content/video-ah-current`, `/oncology`.
- **Два вьюпорта:** 1440×900 и 390×844.
- **Методы:**
  - отрисовка в Chromium;
  - axe-core 4.10 (WCAG 2.2 A/AA и best practices);
  - вычисленные стили каждого текстового узла: цвет, фон, контраст, кегль, межстрочный интервал;
  - размеры кликабельных зон;
  - копирайтинг по гайдам «Тексты в Яндексе» и интерфейсному гайду Яндекс 360;
  - CSS прода: `1nu-h44ci8_w0.css`, `2fiyi6keu8bfc.css`, `1ckefws4uzmd9.css`.

Дизайн-система живёт в артефакте claude.ai, Claude Code его не откроет. Поэтому все нужные значения и правила приведены ниже.

## Как работать с таблицей

1. Иди по приоритетам: P0 → P1 → P2 → P3. Каждая строка — отдельная задача, номер — для коммитов (`fix(ds): DS-07 …`).
2. В колонке «Где искать» — классы и тексты с прода. Ищи их в исходниках через grep.
3. После всех правок:
   - прогони axe на шести страницах в обоих вьюпортах: 0 нарушений `color-contrast`, `heading-order`, `svg-img-alt`, `landmark-complementary-is-top-level`;
   - прогони unit-тесты, typecheck, lint, проверку токенов и продуктовых текстов.

## Что уже соответствует — не трогать

- **Токены:** палитра `--ws-*` совпадает с DS один в один. Все цвета текста и фона на страницах кардиологии — токены DS. Радиусы, отступы, тени и размеры раскладки (`--ws-rail-width` 700, `--ws-sidebar-width` 280, `--ws-touch-target` 44) — тоже из DS.
- **Шрифт и иконки:** шрифт YS Text через `--font-sans`, иконки Lucide со stroke-width 2.
- **Логотип:** настоящий локап `/brand/yandex-med-beta.svg` с β и alt «Яндекс Мед β — главное».
- **Разметка страниц:** `lang="ru"`, skip-link, один `h1` на страницу.
- **Анимации:** у анимированных иллюстраций есть `prefers-reduced-motion`.
- **Чипы:** выбранный чип помечен галочкой и `aria-pressed`, выбор виден не только по цвету.
- **Партнёрский блок** подписан словами «Партнёрский материал · пример формата».

## Приёмка

- **axe-core** на шести страницах × 2 вьюпорта: 0 нарушений уровня serious или critical.
- **Типографика:** вычисленный `line-height / font-size` ≥ 1,2, `font-size` ≥ 11 px.

- **Мобильный вьюпорт:** хит-зоны интерактивных элементов ≥ 44×44.
- **Копирайт:** на всех страницах есть «© 2026 ООО «Яндекс»».
- **Тексты:** в видимом тексте нет `_`-слагов, «мы», слешей в прозе, «выгрузк», «B2D», «прототип».
