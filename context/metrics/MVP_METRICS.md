# MVP Metrics — team of 3.5

## Primary product metric

### Weekly Useful Physicians (WUP)

A verified physician who completes at least one useful task in a week.

Useful task examples:
- successful search → opens authoritative result/source;
- calculator completed;
- guideline section opened and source verified;
- useful item saved/reopened;
- route/VMP information opened.

Do not count a scroll or passive impression as utility.

## Activation

First useful task within 24 hours.

Target from source research:
- 50%+

## Retrieval

- Time to first successful answer: target <20–30 seconds.
- Search → result open: target 70%+.
- No-result rate.
- Reformulation rate.
- Source-open rate.
- "Did this answer the question?" feedback.

## Retention

- D7: target 20%+ for early MVP.
- W4 repeat utility.
- Cohort retention by specialty/job.

## Utility

- sessions using calculator;
- repeat opening of saved material;
- repeat use of recent;
- number of distinct professional jobs completed.

## Trust / quality

- % answers with inspectable source;
- source-link failures;
- clinical-editor correction rate;
- content freshness SLA;
- user reports of incorrect/misleading content;
- AI summary acceptance/rejection by editor.

## Team-efficiency metrics

Because the team is 3.5 people:

- editor minutes per published unit;
- engineering hours per new source integration;
- % of top-50 physician questions covered;
- cost per weekly useful physician;
- number of manual operations per content update;
- time from source update → product update.

## Pilot success gate

Move to the next phase only if:
- activation ≥50%;
- D7 ≥20%;
- search→open ≥70%;
- 70%+ pilot respondents call the product useful in real work;
- no unresolved high-severity clinical content incidents;
- editor workload is scalable.
